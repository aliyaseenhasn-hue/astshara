# دورة الحجز والاستشارة

الدورة المعتمدة في التطبيق:

1. اختيار الباقة
2. اختيار طريقة الاستشارة
3. اختيار الموعد المتاح فعليًا من `lawyer_availability_slots`
4. مراجعة الحجز
5. قيد انتظار الدفع
6. إرسال الدفع
7. قيد معالجة الدفع
8. اعتماد الإدارة للدفع
9. مؤكد
10. ظهور معلومات التواصل لصاحب الحجز فقط وبعد التأكيد
11. قيد التنفيذ
12. مكتمل
13. تسجيل الاستشارة داخليًا
14. التقييم
15. عرض التقييم ومتوسط التقييم للمستخدمين الآخرين

## قواعد التنفيذ

- لا توجد موافقة للمحامي بين إنشاء الحجز والدفع.
- لا يمكن إنشاء حجز بموعد يدوي؛ يجب أن يكون الموعد منشورًا ومتاحًا فعليًا في `lawyer_availability_slots`.
- إرسال الدفع ينقل الحجز إلى `قيد معالجة الدفع`.
- اعتماد الإدارة لعملية الدفع ينقل الحجز إلى `مؤكد`.
- رفض الدفع يعيد الحجز إلى `قيد انتظار الدفع`.
- المحامي لا يستطيع بدء الاستشارة إلا بعد `مؤكد` ووجود دفع بحالة `تم الدفع`.
- إكمال الاستشارة يضع `consultation_status` على `انتهت` ويزيد `completed_consultations` داخليًا.
- لا يمكن إنشاء تقييم إلا للحجز المكتمل والمدفوع، وتقييم واحد فقط لكل حجز.
- متوسط التقييم وعدد التقييمات يظهران في الملف العام للمحامي.
- معلومات التواصل محمية عبر RPC ولا تُعاد إلا لصاحب الحجز وبعد تأكيده.
- جميع حالات الحجز المعروضة للمستخدم باللغة العربية.
